# ✨ Tasnim Binte Monir — Personal Portfolio

> **Live Site → [https://tasnim-ahona.vercel.app/](https://tasnim-ahona.vercel.app/)**

A modern, responsive personal portfolio built with **React + Vite**, featuring a luxurious off-white and golden amber design system, smooth animations, dark/light mode, and a full showcase of projects, skills, and contact info.

## ✨ Features

- ⚡ **Blazing Fast** — Vite-powered build with optimized assets
- 🌗 **Dark / Light Mode** — Smooth theme toggle with localStorage persistence
- 🎨 **Custom Design System** — Off-white, golden amber, charcoal & terracotta palette
- 📱 **Fully Responsive** — Mobile-first layout with fluid grid and flex utilities
- 🪟 **Glassmorphism UI** — Frosted glass cards with safari/webkit support
- 🛍️ **HandiCraft Spotlight** — Featured project with dedicated showcase banner
- 📬 **Contact Suite** — Click-to-copy email & phone, social media profile cards

## 🏃 Run Locally

```bash
# Clone the repo
git clone https://github.com/ahona25/My-Portfolio.git
cd My-Portfolio

# Install dependencies
npm install

# Start dev server
npm run dev
```
